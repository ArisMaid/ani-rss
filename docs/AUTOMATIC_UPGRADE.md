# 自动化洗版（实验功能）

此功能随 `v3.2.52.73` 发布，默认关闭。代码、隔离夹具和真实服务验收是不同阶段；生产 Emby／下载器与真实人工冻结数据集验收尚未完成，不能据此视为已通过无人值守生产验收。历史本地验证记录见验证文档。

## 配置顺序

1. 登录后打开侧栏“洗版”。原版洗版与自动化洗版映射到同一枚举，两个开关全局互斥。
2. 在“执行与设置”保存独立的 Emby 地址、Key 和明确选择的库 ID。可以一次性导入现有 Emby 通知连接；之后各自独立。
3. 设置 Emby → 本地、下载器 → 本地映射，每行格式为 `远端根目录 => 本地根目录`。必须是目录段边界映射，可配置多条，最长匹配优先。
4. 设置 TV、电影输出根目录和下载暂存根目录。目录应预先存在、可访问；暂存根目录必须在 Emby 扫描范围外。执行连接自检检查返回的实际映射样例。
5. 完成所选媒体库索引。首次自动下载要求库已有 24 小时内的完整索引，索引失败会保留上一次完整快照。
6. 在“质量规则”保存自己的规则，再到“季度订阅”选择 Mikan 年份和季度。下拉框读取实际站点菜单，目录预览显示星期／电影／OVA 分组与原条目链接；季度自动生成首播日期区间，不限制后来 BD 或修正版的发布日期。已有自定义日期任务保留原范围，可显式改为季度。
7. 如需 DeepSeek，先保存地址、Key 和模型 ID，获取模型列表或手动输入 ID，执行结构化输出自检，最后启用辅助。更换地址、Key 或模型后重新自检。空 Key 输入保留已保存的值，独立开关可显式清除。
8. 检查目录覆盖、作品身份、季集映射、候选证据和现有版本，最后开启自动模式。

默认规则为字幕组合 > 字幕组 > 分辨率，最低 720p 且要求中文字幕；字幕组排序默认空，表示该维度不参与比较。高维改善可以接受低维下降，硬条件始终生效。完全同级不替换；明确修订比较需启用修订维度。

季度扫描通过 Mikan 的 Bangumi 链接核对身份并关联同条目的实际 RSS，再补充 Bangumi 全部动画类型。Mikan 季度页上的往年长篇不会因为本季更新就改变首播所属范围；没有 Mikan 资源的作品仍可进入监控。来源异常、映射缺失会显示覆盖未完整或重试，不显示为空目录成功。页面复用设置页的标题栏、分段标签、独立滚动与响应式表单。

已保存规则可通过“编辑规则”调整所有维度及排序列表，拖动或点击上下按钮改变从高到低的顺序。编辑弹窗内容单独滚动，保存和取消始终位于底部。删除前先更换全局默认、日期任务、作品覆盖或未完成执行中的引用；删除不会改变媒体文件，历史定义仍保留用于审计。

生效规则采用完整覆盖：作品覆盖优先于日期任务规则，任务规则留空时使用已保存的全局默认规则。多个任务命中同一作品时，优先级较高者生效；同优先级选择创建较早者。任务暂停、范围变化或排除后，作品列表重新显示当前生效任务，未生效时明确标示。

通用 chi／zho 字幕轨标记为“中文，简繁待补证”，可满足必须中文字幕的门槛，但不能凭空当成简体或繁体优先级。章节保存 Bangumi 稳定 ID 与带类型编号；绝对集数可按已核实的章节名或显式映射换算。模型章节建议只来自真实上游章节集合，并须通过唯一标题或播出日期、季及引用校验。导演剪辑、加长版与总集篇单独标识，不能直接替换正片。

独立 OVA／OAD 的编号可对应上游明确的正片章节；名称中的显式 SP／特别篇仍单独处理。版本保护禁止删除该旧版本，仍允许安装更优的新版本。

## 安装与删除

资源先下载到独立暂存目录，核对明确文件清单，再运行 ffprobe 和 ffmpeg 开头／中部／结尾抽样解码。抽样检查不能证明整片没有错误，也不能客观保证画质更好。

可转换的内封文字字幕读取完整但受限的文本：最多 8 条轨道，每条转换最多 8 秒、1 MiB，总体仍受单视频 120 秒处理期限限制。完整可辨识文本优先于冲突的语言标签、轨道标题及内封声明；外挂支持 UTF-8 与带 BOM 的 UTF-16，已观察到的内封能力仍保留。超限、图片字幕或无法辨识的文本不被当成反证；明确硬字幕仍接受发布证据，不要求 OCR。

验证后按当前规则重新比较，使用命名模板加稳定版本后缀安装。优先硬链接，不可用时复制并核验 SHA-256。新版全部可用并登记 active 后，才停止关联旧下载任务（不让下载器删除文件），逐个删除清单中的旧文件。未替换章节、受保护版本、共享源和作品级元数据保留；不递归删除目录。

跨卷复制先独占创建任务专用临时文件，再持久记录归属后写入内容。复制中断可在首次重试恢复；未登记归属的同名临时文件会报 INSTALL_TEMPORARY_IDENTITY_CONFLICT 并保留。qBittorrent 与 Transmission 使用稳定的 hash 引用传输，Aria2 使用 GID；清单中的已知 hash 冲突时不接管或停止该任务。

下载后不符合要求的候选保留下载和诊断，调度继续选择其他资源。其判定指纹包含规则、解析字段及修订号、目标修订号、相关 active 版本与保护状态；条件改变时重新校验已有传输，不重新提交同 hash。已完成下载的空间预约释放，安装需要的空间单独预约。

成功删除旧版后没有本地“一键回滚”。需要旧版只能重新获取资源。通知只使用消息渠道；FileMove、OpenList 和 Shell 不进入自动洗版通知流程。

## 故障处理

| 状态 | 意义与下一步 |
| --- | --- |
| 等待补证／需要修正 | 查看候选的具体比较解释和引用；可以修正解析字段、作品季集映射或 RSS 源，然后重新验证 |
| 等待重试 | 服务、空间或下载器暂不可用；按退避时间重试，也可从执行记录手动重试 |
| 候选暂不可用 | 无进展或超时，保留记录并尝试其他候选，24 小时后可再次探测 |
| 新版可用，清理待重试 | 安装已经提交，不重新下载、不回滚新版；检查旧文件修改、保护、权限或下载器控制冲突 |
| 模式关闭／任务暂停 | 保留候选与已下载文件；重新启用后重新比较当前规则 |
| 安装中恢复 | 根据持久逐文件清单核验最终文件和临时文件；未收敛日志阻止其他安装提交 |

取消安装前任务会停止本功能独占的传输，已下载文件保留。同 hash 仍被其他自动任务使用时转移下载归属和空间预约；普通订阅下载不会被取消。停止失败显示 CANCEL_STOP_PENDING，保留预约并重试；此状态的“重试”只重试停止，不恢复已取消的安装。

同一个配置数据库只允许一个进程，启动会获取独占实例锁。完整配置目录包含 SQLite、配置、会话和提交记录，应一起备份。程序启动先恢复未收敛提交，再启动普通任务。

提交按“作品＋规范章节＋媒体库＋内容版本”写入持久锁，多集按键排序后一次抢占；补充 Bangumi 章节 ID 时仍保留编号别名，避免绕过旧锁。租约过期不能抢走未收敛的文件提交。普通下载、缺集恢复、重命名及完结迁移使用同一文件屏障和持久冲突检查，关闭自动模式也不会放行仍在恢复的章节。首版的实际文件变更仍全局串行。

安装前复核相关章节的 active 版本与质量字段；等待期间基线变化会回到 VERIFYING，复用已下载内容重新比较。其他章节、扫描时间和新补充的引用不会让正常提交反复失效。已进入 INSTALLING 的任务继续按原清单收敛，清理失败保留章节锁，只有完成后释放。

元数据刷新失败不会改变已完成的媒体提交；重试只补缺字段并定向报告新增、修改及已删除路径。已有归档不在默认 TV／电影根目录内时，仍须位于明确授权的媒体库路径映射内。

决策事件保留 180 天，但有效版本、未完成提交和完结档案相关记录不清理；模型响应缓存 90 天失效，输入、模型、端点或提示词版本改变也会重新分析。

## 本地运行与验证

当前本地测试入口：`http://127.0.0.1:17789/#/upgrade`。独立配置在 `output/local-upgrade-test-config`，启动信息在 `output/upgrade-local-instance.json`。首次默认登录为 `admin` / `admin`，建议在测试配置中修改。服务仅监听本机回环地址。

构建不使用 clean，也不清空前端输出：

```powershell
npm --prefix ani-rss-ui run test
npm --prefix ani-rss-ui run build:verify
npm --prefix ani-rss-ui run check:bundle
# 使用 Java 17 和已有 Maven，在项目根目录：
mvn -B -Dskip.frontend=true -Dui.distDir=.verify-dist test package
```

Dockerfile 已增加 ffmpeg 包，Windows／裸机可指定 ffprobe、ffmpeg 可执行路径。依赖自检失败时可以继续发现与比较，但不能进行媒体安装。

## 验收边界

详见 [本地验证记录](AUTOMATIC_UPGRADE_VALIDATION.md)。目前真实 Emby、多架构镜像、三种真实下载器、有效 DeepSeek 账户和生产只读预览仍需要外部验收；不要把隔离接口夹具当成这些服务已经验收。计划要求的至少 30 部作品、300 对人工标注真实候选及开发／冻结验证分离数据集尚未完成，当前合成规则组合不是替代品。

生产部署需要逐项记录 [部署前检查清单](AUTOMATIC_UPGRADE_DEPLOYMENT_CHECKLIST.md) 的实际环境证据；清单本身不表示验收通过。
