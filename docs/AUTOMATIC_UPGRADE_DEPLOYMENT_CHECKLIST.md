# 自动化洗版生产部署前检查清单

本清单对应开发书第 14、15 节。当前仅提供本地开发测试版；勾选项目必须有对应环境的实际证据。本地夹具、构建成功和空库预演不能代替生产部署验收。此次保持本地修改，GitHub 同步等待用户测试结论。

## 包与配置

- [ ] 对拟部署的准确包或镜像记录版本、提交和 SHA-256；所有发布架构实际启动，ffmpeg／ffprobe 探测及媒体抽样解码通过。
- [ ] 升级后未自动开启自动模式；已有显式模式优先，旧配置按 delete／standbyRss／coexist 条件正确迁移。
- [ ] 使用现有完整备份导出保存配置、SQLite、schema 版本及审计清单，在独立实例验证还原。必须包含自动目标、规则、候选、版本、任务、逐文件记录和持久提交锁；仅保存开关 JSON 不够。
- [ ] 拟部署实例没有未收敛文件提交；同一配置目录只有一个持有实例锁的进程。

## 服务与路径

- [ ] 显式选择的 Emby 库完成成功分页索引，Item／MediaSource 多版本及实际总数可核对；首次自动下载前索引不超过 24 小时。
- [ ] Emby → 本地和下载器 → 本地均按真实挂载核验；至少一条自检原路径、映射路径和读取结果记录完整。
- [ ] TV／电影与已有归档目录均在获准根目录内，暂存目录不在任何 Emby 扫描范围内；相似前缀、UNC、符号链接／junction、只读挂载和权限失败按对应环境验证。
- [ ] 目标卷空间覆盖下载、跨卷复制和预留余量；硬链接、复制中断、空间不足及冲突不通过提前删旧版解决。
- [ ] qBittorrent、Transmission、Aria2 分别在独立环境完成提交幂等、文件清单、完成状态、任务停止、不删文件移除和任务消失对账。测试哪种适配器，就保存哪种的真实结果。
- [ ] 配置的 DeepSeek 模型通过列表或手工模型 ID、自检、结构化结果、限流和预算验证；记录日期、模型、提示词版本、请求数与 token 消耗。未启用辅助时界面明确显示。

## 规则、预演与实际闭环

- [ ] 日期按实际首播／发行事实核对；只包含部分不精确日期区间的目标保持补证，没有用创建日期、BD 发售日或父 series 日期代替季度首播日。
- [ ] 已明确保存全局默认规则、任务规则或作品覆盖；规则采用完整覆盖层级，没有隐式字段合并。多个任务命中时显示实际优先级胜出的任务。
- [ ] 对生产媒体库执行只读预演并保存报告：目标、候选证据、实际版本路径、索引新鲜度、决定性字段、拒绝／补证原因及原始统计分母可追溯。
- [ ] 人工标注开发集与冻结集分离，至少 30 部作品、300 对真实案例；固定分类后达到开发书第 13.6 节全部准确性和覆盖率门槛，未重分类或缩小分母掩盖失败。
- [ ] 在隔离库完成首次下载、缺集、单集升级、合集和多版本闭环；新视频、字幕可读取及播放，实际质量重新比较后才安装，旧版逐个明确文件处理。
- [ ] 保护版本、共享字幕、其他章节、共享下载源、作品级 NFO 与海报保留；旧任务整包停止不等于整包删文件。
- [ ] 排队、下载、验证、安装、清理各阶段的模式／规则变更及真实重启通过；复制中断、旧文件外部修改、停止失败、部分删除与 Emby 刷新失败可恢复或停在具体可诊断状态。
- [ ] 普通下载、缺集恢复、重命名、删种、通知与完结迁移不抢占自动任务；完结后目标仍监控，迁移位置与 Emby 映射一致。
- [ ] 每个成功结果关联新文件验证、最终路径、旧文件逐项结果、共享源保留说明、一次成功通知及 Emby 刷新／收录状态。

## 回退

- [ ] 回退前关闭自动调度并收敛提交，保存完整数据库及媒体清单；旧应用不接管新任务。数据库备份不能恢复已经成功删除的旧视频。

配置及路径示例见 [API 与配置示例](AUTOMATIC_UPGRADE_API.md)，恢复行为见 [用户说明](AUTOMATIC_UPGRADE.md)，当前证据和未验收门槛见 [本地验证记录](AUTOMATIC_UPGRADE_VALIDATION.md)，冻结数据格式见 [冻结集说明](UPGRADE_FROZEN_ACCEPTANCE.md)。
