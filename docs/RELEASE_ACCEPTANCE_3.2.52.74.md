# v3.2.52.74 验收与发布范围

日期：2026-10-26。用户确认本轮使用本地隔离媒体目录验收，并保留原有批量下载暂停状态。**未验收真实 Emby，未在生产媒体库执行替换。** 自动洗版继续标记为实验功能。

## 已落实的优化

1. 普通订阅绑定可编辑质量规则，支持字幕组预设、别名和联合发布；与同作品档案共享已发现的历史候选。RSS 窗口消失或临时不可用时仍可使用历史候选，原有匹配、排除和质量门槛继续生效。
2. AnimeGarden 的作品查询及登记别名均执行分页；作品索引有结果时也继续查询别名。旧查询游标会重新执行完整检索。索引空、别名命中、来源失败及身份冲突保留记录。
3. 合集按章节选择对应视频和字幕，保留公共附件；同等的已归属版本不重复提交，更优版本仍参加比较。无法拆分的单视频多集覆盖冲突会保留诊断，不把整包当成已验证的部分章节。
4. 统一 Base32/十六进制哈希；修复重复合集造成的补全状态损失、反复全量读取作品档案及重复刷新下载器快照。质量订阅不会因为任务刚提交就自动停用。
5. 使用作品章节表、明确季号、完整季度合集的“总第”范围转换季度集号与绝对集号。登记映射及人工修正保持优先；缺少明确对应的资源继续补证。第一季发布不会因订阅目标是第二季就被直接改成第二季。
6. 作品候选页增加章节覆盖诊断，分别显示来源扫描、缺集、待补证和身份冲突；候选覆盖不等同于下载完成或入库。裁边视频按实际宽高识别分辨率档位；字幕的发布声明、读取轨道和实际文本证据分别保留。

## 失败记录与限制

- 第一次回环传输被隔离下载器默认的 SSRF 防护拦截，传输为零。该失败任务已暂停并保留，未改动原实例的防护。随后使用新的专用验收 profile，仅在该 profile 允许回环测试，验收后恢复防护并退出。
- 保留前一轮错误提交的 25 个重复合集，未删除媒体或掩盖失败。现有旧下载不会被本次发布批量清理。
- 外部无种、缺元数据、未完成下载、源站暂时失败和未经实际读取的字幕能力仍有明确状态。用户选择保留暂停，因此不把整个季度所有下载完成作为本轮发布结论。
- 本轮只证明上述声明回放、来源查询、代码行为和隔离文件提交边界；不保证穷尽网络全部发布，不宣称无人值守生产 Emby 验收通过。
